# Legalize FCC

FCC Title 47 legislation as Markdown files, inspired by `legalize-es`.

- One section per file
- Structured metadata table at the top of each file
- Source links to eCFR

## Structure

```text
us-fcc/
  0-1.md
  0-3.md
  1-1.md
  ...
```

## Source

- https://www.ecfr.gov/current/title-47
- eCFR Versioner API

## Notes

- This repository is data-only (Markdown corpus), intended to be consumed by apps/websites.
- Generated from current eCFR Title 47 data.
- Not legal advice.
