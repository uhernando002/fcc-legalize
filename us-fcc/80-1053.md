## Full Text

§ 80.1053 Prohibition on certification, manufacture, importation, sale or use of Class A, Class B, Class S, and INMARSAT-E EPIRBs. The manufacture, importation, sale or use of Class A, Class B, Class S, or INMARSAT-E EPIRBs is prohibited. New Class A, Class B, Class S, or INMARSAT-E EPIRBs will no longer be certified by the Commission. [81 FR 90748, Dec. 15, 2016]
